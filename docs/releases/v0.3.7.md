# KOReader Ecosystem 0.3.7

[English](../en/releases/v0.3.7.md) | [Português (Brasil)](v0.3.7.md)

Esta versão prepara o projeto para contribuição open source em um repositório com histórico novo. Inclui documentação bilíngue, imagens de demonstração fictícias e o backlog de desenvolvimento.

O aplicativo mantém os fluxos da versão anterior: biblioteca Calibre, estantes Hardcover, transferência USB/MTP, importação revisável de histórico e backups Restic locais.

## Limitações

- Lotes MTP, recuperação de sidecars e o ciclo completo KOReader → Hardcover ainda exigem validação em dispositivo físico.
- Backup remoto e restauração independente continuam pendentes. Atualizações automáticas dependem de assinatura e rollback confiáveis.
- O instalador não é assinado digitalmente. Confira os hashes SHA-256 disponíveis na release.
