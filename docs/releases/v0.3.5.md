# KOReader Ecosystem 0.3.5

## Mapeamento de colunas para importar histórico de leitura

- Adicionada uma etapa revisável de mapeamento de colunas para CSVs do Goodreads, StoryGraph e Maratona. As sugestões reconhecem cabeçalhos comuns em inglês e português do Brasil.
- Título e autor são obrigatórios. ISBN, identificador externo, nota, status, tags, contagem de leituras e datas são opcionais.
- Resenhas são ignoradas por padrão. Para importá-las, mapeie a coluna explicitamente; elas ficam ocultas na prévia e só são incluídas em uma exportação se você optar por isso.
- A aplicação lê primeiro apenas os cabeçalhos. Nenhuma linha é preparada até você revisar o mapeamento e escolher **Pré-visualizar com estas colunas**.
- Somente valores das colunas mapeadas são mantidos. Colunas não mapeadas e notas privadas são descartadas. O caminho do arquivo permanece no processo principal do Electron; a interface recebe um identificador opaco e temporário, nomes de cabeçalho, hash do arquivo e sugestões — nunca o caminho ou valores das linhas.
- A prévia verifica novamente o hash antes de ler as linhas; se o CSV mudar, é preciso selecioná-lo outra vez.
- A confirmação da importação continua local. Ela não altera livros, status, notas ou edições no Calibre ou no Hardcover. A correspondência de edições continua sendo uma etapa separada.
- Uma combinação de origem e bytes do CSV identifica um único lote. Se o arquivo já tiver sido importado com outro mapeamento, a aplicação mantém o lote existente e informa o conflito; não mistura nem substitui linhas.
- Arquivos com mais de 256 colunas ou cabeçalhos maiores que 256 caracteres são rejeitados.

## Validação

O workflow de release executa as suítes Python e desktop, lint, formatação, checagem de tipos, varredura de segredos e empacotamento Windows. Depois que esses trabalhos passam, a release do GitHub inclui o instalador Setup, o ZIP portátil e os hashes SHA-256.

## Limitações conhecidas

- Goodreads, StoryGraph e Maratona são intercâmbios locais por CSV, não integrações ao vivo com as contas.
- Importar uma lista não sincroniza os registros com Calibre ou Hardcover.
- O aplicativo não tem assinatura digital; o Windows pode exibir um aviso de editor desconhecido.
