# KOReader Ecosystem v0.2.4

## Novidades

- Snapshots Restic incluem o estado local allowlisted do aplicativo junto com Calibre e, quando selecionado, Kindle.
- O banco SQLite KOReader–Calibre é copiado pela Online Backup API e passa por `integrity_check` antes de entrar no snapshot.
- Configuração sem credenciais e histórico sanitizado de operações entram no snapshot; tokens, senha Restic, staging, cache temporário e cópias de rollback ficam fora.
- Snapshots novos recebem a tag `application-state-v1`; a interface distingue os snapshots antigos que não contêm o estado do aplicativo.
- A verificação de restauração compara também o manifesto do estado local. A restauração cria uma pasta nova e não reimporta esses arquivos ao perfil ativo.
- O backup continua funcionando quando ainda não há estado local elegível para incluir; nesse caso, o Calibre é armazenado como única fonte do snapshot.

## Limites

- O backup local está disponível; a cópia remota e a restauração independente ainda exigem validação.
- A aplicação ainda não oferece ação para reimportar o estado recuperado ao perfil do Windows.
- A validação MTP e a leitura real no Kindle continuam pendentes de conferência física.
- A sincronização KOReader–Hardcover ainda precisa ser validada com uma leitura real e conferida no Hardcover.

## Arquivos Windows

- `KOReaderEcosystem-Setup.exe` — instalador Windows x64.
- `KOReaderEcosystem-Windows-x64.zip` — pacote portátil Windows x64.
- `SHA256SUMS.txt` — hashes dos dois arquivos de distribuição.
