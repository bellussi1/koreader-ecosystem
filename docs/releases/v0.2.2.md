# KOReader Ecosystem v0.2.2

Esta versão atualiza a interface Electron e integra o gerenciamento local de backups. A publicação é feita pela automação do GitHub depois que as verificações e o empacotamento Windows terminarem com sucesso.

## Novidades

- Reúne biblioteca Calibre, Hardcover e fluxos do Kindle nas três páginas já existentes.
- Melhora filtros, ordenação e visualização da biblioteca.
- Mostra a presença do Kindle por USB/MTP automaticamente e permite conferir a última consulta ao Hardcover.
- Permite criar snapshots Restic somente do Calibre ou do Calibre e Kindle, listar snapshots e restaurá-los para uma pasta nova.
- Valida metadata.db e a integridade do snapshot; quando solicitado pela interface, restaura temporariamente o backup e compara os arquivos.
- Permite cadastrar e trocar a senha Restic pelo Gerenciador de Credenciais do Windows. Uma senha nova só substitui a anterior se abrir o repositório existente.
- Mostra o escopo de cada snapshot sem expor tags livres, caminhos ou outros metadados privados.

## Limites conhecidos

- Os snapshots ficam no computador atual. O backup remoto continua adiado e não protege contra perda do disco.
- O snapshot de Calibre e Kindle ainda não inclui o estado SQLite da aplicação.
- O ciclo USB precisa de uma transferência confirmada no Kindle físico; a sondagem mais recente do Windows encontrou zero dispositivos.
- O fluxo completo KOReader → Hardcover precisa de uma leitura real com a chave Hardcover fornecida por prompt local seguro. Chaves coladas em conversas não devem ser reutilizadas.
- Revise as alterações propostas na prévia KOReader–Calibre antes de aprovar qualquer gravação.
- Notas de diário e avaliações Hardcover continuam sendo ações manuais.

## Arquivos do pacote Windows

- `KOReaderEcosystem-Setup.exe` — instalador Windows x64.
- `KOReaderEcosystem-Windows-x64.zip` — pacote portátil Windows x64.
- `SHA256SUMS.txt` — hashes SHA-256 dos dois pacotes.

O instalador não possui assinatura digital. A release só deve ser publicada depois de CI, empacotamento, validação dos hashes e conferência do executável.
