# KOReader Ecosystem v0.1.2

Primeira prévia da interface Electron para Windows x64.

## Novidades

- Catálogo local do Calibre com busca por título, autor, ISBN e ID.
- Capas carregadas da biblioteca local, convertidas em miniaturas e servidas pelo protocolo interno do aplicativo.
- Respostas do serviço Python codificadas de forma compatível com nomes e metadados Unicode no Windows.
- Instalador Squirrel e pacote ZIP para extrair manualmente.

## Limites desta versão

- A biblioteca Electron é somente leitura.
- Envio de livros, edição de metadados, backup, sincronização USB e ações Hardcover ainda não foram migrados para essa interface.
- As páginas Kindle e Configuração são uma prévia visual; use a CLI ou a aplicação PySide6 legada no checkout local para operações já implementadas.
- O instalador ainda não tem assinatura digital. Confira `SHA256SUMS.txt` antes de executá-lo.
- O app precisa rodar no Windows com acesso à biblioteca do Calibre. Ele não é hospedado nem executa como serviço em nuvem.

## Arquivos

- `KOReaderEcosystem-Setup.exe` — instalador Windows x64.
- `KOReaderEcosystem-Windows-x64.zip` — diretório completo do aplicativo, sem instalador.
- `SHA256SUMS.txt` — hashes SHA-256 dos dois arquivos acima.
