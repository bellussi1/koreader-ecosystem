# KOReader Ecosystem 0.3.8

[English](../en/releases/v0.3.8.md) | [Português (Brasil)](v0.3.8.md)

Esta versão organiza as verificações do projeto e facilita a participação de novos contribuidores. Os fluxos de leitura e sincronização do aplicativo permanecem os mesmos.

- Os workflows identificam separadamente os testes Python, o pacote Windows e a varredura de segredos. Um novo commit cancela apenas execuções antigas do mesmo pull request; releases não são canceladas automaticamente.
- Os guias de contribuição explicam as verificações, e um modelo bilíngue ajuda a descrever e testar pull requests.
- As issues para iniciantes incluem arquivos e critérios de aceite mais claros.

O instalador não é assinado digitalmente. Confira os hashes SHA-256 da release. Lotes MTP, recuperação de sidecars e o ciclo completo KOReader–Hardcover ainda precisam de validação adicional em aparelho físico.
