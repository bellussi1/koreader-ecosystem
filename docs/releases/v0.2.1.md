# KOReader Ecosystem v0.2.1

Release Windows x64.

## Correções

- Corrige o ícone do KOReader Ecosystem na lista de aplicativos do Windows. O instalador Squirrel registrava o ícone padrão do Electron; agora a aplicação aponta o registro do Windows para o executável instalado, que contém o ícone do livro.

## Downloads

- `KOReaderEcosystem-Setup.exe` — instalador Windows x64.
- `KOReaderEcosystem-Windows-x64.zip` — pacote portátil Windows x64.
- `SHA256SUMS.txt` — hashes SHA-256 dos dois pacotes.

O instalador continua sem assinatura digital. Para validar o pacote, confira o hash em `SHA256SUMS.txt`.
