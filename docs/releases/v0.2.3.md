# KOReader Ecosystem v0.2.3

Esta preparação foi substituída pela v0.2.4 após os testes do CI falharem na tag `v0.2.3`. A tag existente não será reutilizada; os recursos desta versão foram incorporados à release seguinte.

## Novidades

- Snapshots Restic passam a incluir o estado local allowlisted do aplicativo junto com Calibre e, quando selecionado, Kindle.
- O banco SQLite KOReader–Calibre é copiado pela Online Backup API e tem `integrity_check` validado antes de entrar no snapshot.
- Configuração sem credenciais e histórico sanitizado de operações entram no snapshot; tokens, senha Restic, staging, cache temporário e cópias de rollback ficam fora.
- Snapshots novos recebem a tag `application-state-v1`; a interface distingue os snapshots antigos que ainda não contêm o estado do aplicativo.
- A verificação de restauração compara também o manifesto do estado local. A restauração segue para uma pasta nova e não reimporta automaticamente esses arquivos ao perfil ativo.
- Um snapshot real local com 676 arquivos Calibre e 3 arquivos de estado passou na verificação Restic e em restauração temporária.

## Limites

- O backup local está disponível; a cópia remota e a restauração independente ainda exigem validação.
- A aplicação ainda não oferece uma ação para reimportar o estado recuperado ao perfil do Windows.
- A validação MTP e a leitura real do Kindle continuam pendentes de acesso ao dispositivo.
- A sincronização KOReader–Hardcover ainda precisa de uma leitura real e conferência no Hardcover.

## Arquivos Windows

- `KOReaderEcosystem-Setup.exe` — instalador Windows x64.
- `KOReaderEcosystem-Windows-x64.zip` — pacote portátil Windows x64.
- `SHA256SUMS.txt` — hashes dos dois arquivos de distribuição.
