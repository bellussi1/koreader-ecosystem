# KOReader Ecosystem v0.3.3

[English](../en/releases/v0.3.3.md) | [Português (Brasil)](v0.3.3.md)

## Novidades

- Os controles de ordenação e filtro agora têm alvos de 48 px; o filtro abre ao clicar em qualquer parte do botão.
- A ordenação aplica explicitamente a fonte Inter. Os títulos de livros continuam em Lora.
- Os controles preservam foco visível, navegação por teclado e os rótulos acessíveis em português e inglês.

## Arquivos Windows

- `KOReaderEcosystem-Setup.exe` — instalador Windows x64.
- `KOReaderEcosystem-Windows-x64.zip` — pacote portátil Windows x64.
- `SHA256SUMS.txt` — hashes SHA-256 dos dois arquivos.

O instalador não possui assinatura digital.
