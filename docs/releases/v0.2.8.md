# KOReader Ecosystem v0.2.8

[English](../en/releases/v0.2.8.md) | [Português (Brasil)](v0.2.8.md)

## Novidades

- Alinha o nome do pacote Python, serviço do aplicativo, perfil local, credenciais e novas tags Restic a **KOReader Ecosystem**.
- Migra o perfil local antigo para `%LOCALAPPDATA%\KOReaderEcosystem` na primeira abertura. Se a pasta estiver bloqueada, o aplicativo continua usando o perfil existente; não apaga a cópia antiga quando a migração de credenciais é feita.
- Lê as credenciais do Gerenciador de Credenciais com o identificador anterior e as copia para o novo identificador após verificar a gravação.
- Continua reconhecendo snapshots Restic com a tag antiga e cria snapshots novos com a tag KOReader Ecosystem.
- Renomeia o executável auxiliar do desktop e inclui documentação pública em inglês e português, imagens de demonstração, ícone, guia de contribuição e formulários de issue.
- A prévia KOReader–Calibre agora copia somente estatísticas e metadados de leitura necessários para a análise, sem fazer uma cópia temporária de todo o Kindle.

## Compatibilidade e limites

- A migração automática cobre o caminho padrão do perfil local. Caminhos definidos pelo usuário permanecem como estavam.
- Credenciais e snapshots legados são preservados; a versão nova não os apaga.
- A edição de metadados Calibre e as ações Hardcover continuam separadas.
- Fluxos de transferência e sincronização ainda precisam da validação no dispositivo descrita no README.
- O instalador não possui assinatura digital.

## Arquivos Windows

- `KOReaderEcosystem-Setup.exe` — instalador Windows x64.
- `KOReaderEcosystem-Windows-x64.zip` — pacote portátil Windows x64.
- `SHA256SUMS.txt` — hashes SHA-256 dos dois arquivos.
