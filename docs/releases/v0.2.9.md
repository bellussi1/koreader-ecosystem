# KOReader Ecosystem v0.2.9

[English](../en/releases/v0.2.9.md) | [Português (Brasil)](v0.2.9.md)

## Novidades

- Adiciona inglês e português do Brasil como idiomas da interface, com seletor em **Configuração → Idioma**. Na primeira abertura, o aplicativo acompanha o idioma do Windows.
- Traduz biblioteca, estantes Hardcover, sincronização KOReader, histórico, backup, restauração e mensagens comuns de erro.
- Inclui capturas em inglês com dados e capas fictícios no README para apresentar o projeto a contribuidores internacionais.
- Corrige um rótulo do estado do serviço local que permanecia em português na interface inglesa.

## Compatibilidade e limites

- O idioma escolhido fica salvo nas preferências locais deste aplicativo.
- Nenhum formato de dados ou sincronização remota foi alterado nesta versão.
- A transferência USB/MTP e o ciclo real KOReader–Hardcover continuam dependendo de validação no dispositivo físico.
- O instalador não possui assinatura digital.

## Arquivos Windows

- `KOReaderEcosystem-Setup.exe` — instalador Windows x64.
- `KOReaderEcosystem-Windows-x64.zip` — pacote portátil Windows x64.
- `SHA256SUMS.txt` — hashes SHA-256 dos dois arquivos.
