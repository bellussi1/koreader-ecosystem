# KOReader Ecosystem v0.3.4

[English](../en/releases/v0.3.4.md) | [Português (Brasil)](v0.3.4.md)

## Novidades

- A tela **Configuração → Conexão Hardcover** identifica individualmente as ações ambíguas da fila, com livro quando há título no cache, tipo de ação, estado e horário.
- O texto de notas de diário nunca é enviado à interface. A lista é lida do SQLite local e não faz chamadas à API Hardcover.
- Depois de conferir a conta, você pode marcar uma ação como já visível no Hardcover ou encerrar apenas a pendência local sem confirmar o resultado remoto. Nenhuma opção altera a conta.
- As decisões ficam registradas localmente no SQLite v5. Ações resolvidas deixam de aparecer como pendentes e não podem ser reenviadas por uma reconciliação concorrente.

## Arquivos Windows

- `KOReaderEcosystem-Setup.exe` — instalador Windows x64.
- `KOReaderEcosystem-Windows-x64.zip` — pacote portátil Windows x64.
- `SHA256SUMS.txt` — hashes SHA-256 dos dois arquivos.

O instalador não possui assinatura digital.
