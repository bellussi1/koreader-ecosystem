# KOReader Ecosystem v0.2.5

[English](v0.2.5.md) | [Português (Brasil)](../../releases/v0.2.5.md)

## Highlights

- The library uses two-row pagination and shared UI controls for more consistent buttons and selectors.
- Restic snapshots now preserve the local Hardcover request ledger, which contains timestamps only and prevents restoring app state from silently resetting the local quota.
- A Hardcover API usage panel and persistent local counter cap the Windows app at 1,000 requests per rolling 24 hours and 25 per minute.
- The included KOReader plugin patch displays sync status and time, retries after connectivity returns, detects progress conflicts, and caps the plugin at 2,000 requests per 24 hours and 25 per minute.
- Together, the project's two components are capped locally at 3,000 requests per day and 50 per minute.
- MTP transfer verification compares file hashes without depending on Windows-specific path separators while preserving file-count and integrity checks.
- Expanded English documentation, with contributor guides and security policies in both languages.

## Known limitations

- App and plugin quotas are local and cannot count the Hardcover website or other clients using the account. The API documentation reviewed lists 60 requests per minute but does not specify a daily allowance on that page; the app cannot guarantee total usage or free-plan eligibility.
- Installing the patch on a Kindle and completing an online/offline reading cycle still require confirmation on the device. CI does not test physical hardware.
- The Electron metadata form does not include description/comments; use Calibre for that field, covers, and custom fields.
- Journal entries and ratings remain manual. Reading progress sync does not automatically update these fields in Calibre.
- Remote backup and restore from an external service still need to be configured and validated.
- Restore creates a new folder; applying recovered state to the active profile remains manual.

## Windows files

- `KOReaderEcosystem-Windows-x64.zip` — portable Windows x64 package.
- `SHA256SUMS.txt` — SHA-256 hashes for both distribution files.
