# KOReader Ecosystem v0.3.3

[English](v0.3.3.md) | [Português (Brasil)](../../releases/v0.3.3.md)

## What's new

- Sorting and filtering controls now have 48 px hit areas; the filter opens when any part of its button is clicked.
- The sort control explicitly uses Inter. Book titles remain in Lora.
- Controls retain visible focus, keyboard navigation, and accessible labels in English and Brazilian Portuguese.

## Windows files

- `KOReaderEcosystem-Setup.exe` — Windows x64 installer.
- `KOReaderEcosystem-Windows-x64.zip` — portable Windows x64 package.
- `SHA256SUMS.txt` — SHA-256 hashes for both files.

The installer is not digitally signed.
