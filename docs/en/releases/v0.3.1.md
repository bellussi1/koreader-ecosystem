# KOReader Ecosystem v0.3.1

[English](v0.3.1.md) | [Português (Brasil)](../../releases/v0.3.1.md)

## What's new

- CSV reading-history previews now suggest matching local Calibre and Hardcover records.
- A known ISBN or provider ID produces an exact candidate; title + author produces a suggestion that still needs review.
- Multiple or conflicting matches are flagged. No record is linked automatically.
- Matching uses catalogs already loaded in the view and makes no additional Hardcover requests.

## Limits

- Suggestions do not change the CSV, Calibre, Hardcover, or KOReader.
- A title suggestion also requires a matching author; title alone is insufficient.
- Hardcover editions and statuses are not inferred from local digital editions. CSV column mapping remains pending.
- USB/MTP transfer and the real KOReader–Hardcover sync loop still need physical-device validation.
- The installer is not digitally signed.

## Windows files

- `KOReaderEcosystem-Setup.exe` — Windows x64 installer.
- `KOReaderEcosystem-Windows-x64.zip` — portable Windows x64 package.
- `SHA256SUMS.txt` — SHA-256 hashes for both files.
