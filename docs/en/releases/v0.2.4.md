# KOReader Ecosystem v0.2.4

[English](v0.2.4.md) | [Português (Brasil)](../../releases/v0.2.4.md)

## New features

- Restic snapshots include allowlisted local app state with Calibre and, when selected, Kindle.
- The KOReader–Calibre SQLite database is copied with SQLite's Online Backup API and checked before entering a snapshot.
- Configuration without credentials and sanitized operation history are included; tokens, the Restic password, staging, temporary cache, and plugin rollback copies are excluded.
- New snapshots receive the `application-state-v1` tag; the UI distinguishes older snapshots that do not contain app state.
- Restore verification also compares the app-state manifest. Restore creates a new folder and does not reimport the files into the active profile.
- Backup still works when no eligible local app state is available; in that case, Calibre is the only snapshot source.

## Limitations

- Backups remain on the same disk as their sources. Remote copy is deferred.
- The app does not yet provide an action to reimport recovered state into the active Windows profile.
- Physical MTP transfer and on-device reading sync still need end-to-end validation.
- KOReader–Hardcover sync still needs to be checked with a real reading session.

## Windows files

- `KOReaderEcosystem-Setup.exe` — Windows x64 installer.
- `KOReaderEcosystem-Windows-x64.zip` — portable Windows x64 package.
- `SHA256SUMS.txt` — SHA-256 hashes for both distribution files.
