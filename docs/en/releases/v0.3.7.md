# KOReader Ecosystem 0.3.7

[English](v0.3.7.md) | [Português (Brasil)](../../releases/v0.3.7.md)

This version prepares the project for open-source contributions in a repository with fresh history. It includes bilingual documentation, fictional demo screenshots, and a development backlog.

The app retains the previous workflows: Calibre library management, Hardcover shelves, USB/MTP transfer, reviewable history import, and local Restic backups.

## Limitations

- Batch MTP, sidecar recovery, and the complete KOReader → Hardcover lifecycle still require physical-device validation.
- Remote backup and independent restore remain pending. Automatic updates depend on reliable signing and rollback.
- The installer is not digitally signed. Verify the SHA-256 checksums included with the release.
