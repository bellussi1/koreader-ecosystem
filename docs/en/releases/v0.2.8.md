# KOReader Ecosystem v0.2.8

[English](v0.2.8.md) | [Português (Brasil)](../../releases/v0.2.8.md)

## What's new

- Aligns the Python distribution, desktop service, local profile, credential service, and new Restic tags with the **KOReader Ecosystem** name.
- Migrates the default local profile to `%LOCALAPPDATA%\KOReaderEcosystem` on first launch. If Windows cannot move the folder, the app continues using the existing profile; credential migration does not delete the old copy.
- Reads credentials from the previous Windows Credential Manager service and copies each value to the new service after verifying the write.
- Continues to recognize old Restic snapshots and writes new snapshots with the KOReader Ecosystem tag.
- Renames the desktop helper executable and adds public English and Portuguese documentation, demo screenshots, the app icon, contributor guidance, and issue forms.
- KOReader–Calibre previews now stage only the reading statistics and metadata required for analysis instead of temporarily copying the entire Kindle.

## Compatibility and limitations

- Automatic migration covers the default app profile path. User-configured paths are preserved.
- Legacy credentials and backup snapshots are kept; the new version does not delete them.
- Calibre metadata editing and Hardcover shelf actions remain separate.
- Device transfer and reading sync still need the physical-device validation described in the README.
- The installer is not digitally signed.

## Windows files

- `KOReaderEcosystem-Setup.exe` — Windows x64 installer.
- `KOReaderEcosystem-Windows-x64.zip` — portable Windows x64 package.
- `SHA256SUMS.txt` — SHA-256 hashes for both files.
