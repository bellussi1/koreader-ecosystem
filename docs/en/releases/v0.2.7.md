# KOReader Ecosystem v0.2.7

[English](v0.2.7.md) | [Português (Brasil)](../../releases/v0.2.7.md)

## Highlights

- Persistent local cache for Hardcover library pages and current reading. The UI shows the data source and timestamp; cached data is used only after transient failures or request-limit exhaustion and expires after 30 days.
- Persistent outbox records mutations before sending. Ambiguous responses and interrupted sends require review and are never replayed automatically.
- Guided app-profile recovery from a folder created by a verified Restic restore: preview, explicit confirmation, checkpoint of the current profile, configuration and SQLite recovery, then an app restart. Tokens and passwords remain in Windows Credential Manager.
- Calibre editor support for selecting a cover, editing eligible single-value custom fields, and applying reviewed batch tag changes. Writes require a backup and a catalog reread.
- Clearer library, offline-cache, and profile-recovery status.

## Known limitations

- Profile recovery has automated fixture coverage; validation with a real Restic snapshot after reinstall is still pending.
- Kindle does not provide an independent MTP checksum. Name collisions, interrupted transfers, and batch transfers still need validation before bulk use.
- Full synchronization of progress, status, dates, ratings, notes, and annotations across KOReader, Hardcover, and Calibre still needs a real reading-cycle validation.
- Remote backup remains disabled. The Windows installer is not digitally signed.
