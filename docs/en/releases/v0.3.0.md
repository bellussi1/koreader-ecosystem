# KOReader Ecosystem v0.3.0

[English](v0.3.0.md) | [Português (Brasil)](../../releases/v0.3.0.md)

## What's new

- Import reading history from CSV files compatible with Goodreads, StoryGraph, and Maratona. The paginated preview requires confirmation before records are stored locally.
- Export confirmed batches in Goodreads-compatible CSV with spreadsheet formula protection. Reviews are included only when you opt in; private notes are never exported.
- Keep the workflow inside the Library page, available in English and Brazilian Portuguese.
- Persist batches and rows in local SQLite with idempotent imports and bounded file and field sizes.

## Compatibility and limitations

- Importing or confirming a CSV does not update Hardcover, Calibre, KOReader, or Kindle. Export creates a local file for manual import elsewhere.
- This release does not create automatic record links; editions, statuses, and fields without an equivalent remain subject to review.
- CSV cannot fully represent KOReader sessions, page-level progress, annotations, or every reread.
- USB/MTP transfer and the real KOReader–Hardcover reading loop still need validation on the physical Kindle.
- The installer is not digitally signed.

## Windows files

- `KOReaderEcosystem-Setup.exe` — Windows x64 installer.
- `KOReaderEcosystem-Windows-x64.zip` — portable Windows x64 package.
- `SHA256SUMS.txt` — SHA-256 hashes for both files.
