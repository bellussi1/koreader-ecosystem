# KOReader Ecosystem v0.1.2

[English](v0.1.2.md) | [Português (Brasil)](../../releases/v0.1.2.md)

First Electron UI preview for Windows x64.

## New features

- Local Calibre catalog with search by title, author, ISBN, and ID.
- Covers loaded from the local library, converted to thumbnails, and served through the app's internal protocol.
- Python service responses support Unicode names and metadata on Windows.
- Squirrel installer and a ZIP package for manual extraction.

## Limitations

- The Electron library view is read-only.
- Book transfer, metadata editing, backup, USB sync, and Hardcover actions have not yet been migrated to this interface.
- Kindle and Settings pages are visual previews; use the CLI or legacy PySide6 app for operations available in the local checkout.
- The installer is not digitally signed. Verify `SHA256SUMS.txt` before running it.
- The app must run on Windows with access to the Calibre library. It is not hosted and does not run as a cloud service.

## Files

- `KOReaderEcosystem-Setup.exe` — Windows x64 installer.
- `KOReaderEcosystem-Windows-x64.zip` — complete app directory without an installer.
- `SHA256SUMS.txt` — SHA-256 hashes for both files.
