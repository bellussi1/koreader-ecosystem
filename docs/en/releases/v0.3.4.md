# KOReader Ecosystem v0.3.4

[English](v0.3.4.md) | [Português (Brasil)](../../releases/v0.3.4.md)

## What's new

- **Settings → Hardcover connection** identifies ambiguous queue actions individually, showing the book when its title is in the local cache, action type, state, and time.
- Journal text is never sent to the interface. The list is read from local SQLite and makes no Hardcover API calls.
- After checking the account, you can mark an action as already visible on Hardcover or close only the local item without confirming the remote result. Neither choice changes the account.
- Decisions are recorded in local SQLite v5. Resolved actions stop appearing as pending and cannot be resent by a concurrent reconciliation.

## Windows files

- `KOReaderEcosystem-Setup.exe` — Windows x64 installer.
- `KOReaderEcosystem-Windows-x64.zip` — portable Windows x64 package.
- `SHA256SUMS.txt` — SHA-256 hashes for both files.

The installer is not digitally signed.
