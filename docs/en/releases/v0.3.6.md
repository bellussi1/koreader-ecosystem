# KOReader Ecosystem 0.3.6

## Reading history and local automation

- Imported KOReader history is stored in the local profile as events and annotation versions. A preview can propose progress, status, rating, note, and annotations for dedicated Calibre columns; links and conflicts require review before applying.
- Projection requires the exact Calibre book UUID, creates a backup before writing, checks that Calibre is closed, and rereads fields after application. It does not change Hardcover status, rating, journal, or edition.
- Settings now offers optional daily backups through Windows Task Scheduler and optional backups when the device connects over USB. Both are off by default and require the Restic password stored in Windows Credential Manager.
- USB backup requires KOReader Ecosystem to be open, waits for two stable device checks, and also works when the option was already enabled as the app opens with the device connected. Enabling it while the device is already connected takes effect on the next reconnect.
- Backups, protected Calibre/MTP writes, and profile recovery share a cross-process lock. Interrupted runs are recorded for diagnosis; automation never force-terminates an active copy.
- Shelf cards keep status and format labels in consistent positions; edit and send actions use a uniform height.

## Known limitations

- Automation stays disabled until selected in Settings. Testing Task Scheduler installation and execution on this Windows profile remains pending.
- Batch MTP transfer, KOReader sidecar restoration, and a real KOReader → Hardcover reading flow still require validation on the physical device. The roadmap tracks these gates separately.
- Calibre projection is local and reviewable. Ratings, journal entries, and annotations are not sent to Hardcover automatically.
- The app is not digitally signed. Windows may show an unknown-publisher notice.

## Packages

The GitHub release includes Setup, a portable ZIP, and SHA-256 checksums after the Windows and integrity workflows pass.
