# KOReader Ecosystem 0.3.8

[English](v0.3.8.md) | [Português (Brasil)](../../releases/v0.3.8.md)

This release organizes project checks and makes it easier for new contributors to participate. Reading and synchronization workflows remain unchanged.

- Workflows identify Python checks, the Windows package, and the secret scan separately. A new commit cancels only older runs of the same pull request; releases are not automatically cancelled.
- Contributor guides explain the checks, and a bilingual pull request template helps describe and verify changes.
- First-contribution issues include clearer files and acceptance criteria.

The installer is not digitally signed. Verify the release SHA-256 checksums. Batch MTP, sidecar recovery, and the complete KOReader–Hardcover lifecycle still need additional physical-device validation.
