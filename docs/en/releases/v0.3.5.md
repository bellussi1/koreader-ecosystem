# KOReader Ecosystem 0.3.5

## Reading-history CSV column mapping

- Added a reviewable column-mapping step for Goodreads, StoryGraph, and Maratona CSV imports. Suggested aliases cover common English and Brazilian Portuguese headers.
- Title and author must be mapped. ISBNs, external IDs, rating, reading status, shelves, read count, and dates are optional.
- Reviews are ignored by default. Map the column explicitly to import them; reviews stay hidden in the preview and are included in an export only if you opt in.
- The app reads only the header for this first step. No rows are staged until the user reviews the mapping and chooses **Preview using these columns**.
- Only values from mapped columns are kept. Unmapped columns and private notes are discarded. The file path stays in the Electron main process. The renderer receives an opaque, expiring selection ID, header names, a file digest, and suggestions; it never receives the selected path or row values.
- The mapped preview checks the file digest again before parsing, so changing the CSV after header inspection requires selecting it again.
- Import confirmation remains local. It does not change Calibre or Hardcover records, statuses, ratings, or editions. Edition matching remains a separate review step.
- One source and exact CSV byte sequence identify a single batch. If the file was imported with a different mapping, the app keeps the existing batch and reports the conflict; it does not mix or replace rows.
- Added bounds for CSVs with more than 256 columns or headers longer than 256 characters.

## Validation

The release workflow runs the Python and desktop test suites, lint, formatting, type checks, secret scan, and Windows packaging. The GitHub release attaches the Setup installer, portable ZIP, and SHA-256 checksums after those jobs pass.

## Known limitations

- Goodreads, StoryGraph, and Maratona imports are local CSV interchange, not live account integrations.
- Importing a batch does not synchronize it to Calibre or Hardcover.
- The app is not digitally signed. Windows may show an unknown-publisher notice.
