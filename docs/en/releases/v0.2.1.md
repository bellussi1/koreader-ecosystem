# KOReader Ecosystem v0.2.1

[English](v0.2.1.md) | [Português (Brasil)](../../releases/v0.2.1.md)

Windows x64 release.

## Fixes

- Fixes the KOReader Ecosystem icon in the Windows application list. Squirrel previously registered the default Electron icon; the app now points the Windows uninstall entry to the installed executable, which contains the book icon.

## Downloads

- `KOReaderEcosystem-Setup.exe` — Windows x64 installer.
- `KOReaderEcosystem-Windows-x64.zip` — portable Windows x64 package.
- `SHA256SUMS.txt` — SHA-256 hashes for both packages.

The installer is not digitally signed. Verify the hashes in `SHA256SUMS.txt` before running it.
