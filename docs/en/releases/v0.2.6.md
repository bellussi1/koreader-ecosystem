# KOReader Ecosystem v0.2.6

[English](v0.2.6.md) | [Português (Brasil)](../../releases/v0.2.6.md)

## Highlights

- Import KOReader reading history into local SQLite, including page events, progress, and annotation revisions. Sessions grouped by inactivity gaps are clearly marked as estimated.
- Reviewable preview and manual linking between KOReader history and Calibre books. Local import does not modify the Kindle or send changes to Hardcover.
- Migrate legacy local records into `application-state.sqlite3` without deleting their sources, and include the database in verified Restic snapshots.
- Hybrid MTP verification: WPD SHA-256 readback for files accessible under `system` and `koreader`, and Windows Shell readback for documents, `.sdr` sidecars, and unknown roots. Ambiguous paths, inconsistent sizes, and mismatched hashes are rejected.
- Fix the app icon used by Start Menu shortcuts created or updated by Squirrel.
- Error reporting distinguishes backup failures from Kindle disconnection.

## Known limitations

- Automated checks passed, but they do not replace a transfer test on physical Kindle hardware. Sending the full library remains pending.
- Kindle MTP does not provide an independent checksum. Readback catches common mismatches but cannot prove that identical errors did not occur during both copies.
- Importing history into the app does not automatically sync notes, ratings, or status to Hardcover. The real KOReader–Hardcover reading cycle still needs device validation.
- Calibre projection requires explicit linking and review. Sessions derived from 30-minute gaps are estimates.
- Remote backup remains disabled. The installer is not digitally signed.
