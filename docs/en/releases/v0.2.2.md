# KOReader Ecosystem v0.2.2

[English](v0.2.2.md) | [Português (Brasil)](../../releases/v0.2.2.md)

This release updates the Electron UI and adds local backup management. GitHub automation publishes the release after checks and Windows packaging succeed.

## New features

- Brings the Calibre library, Hardcover, and Kindle workflows together in the existing three pages.
- Improves library filters, sorting, and visualization.
- Detects Kindle presence over USB/MTP and shows the last successful Hardcover query.
- Creates Restic snapshots of Calibre alone or Calibre plus Kindle, lists snapshots, and restores to a new folder.
- Validates the Calibre database and snapshot integrity; when requested, restores a temporary copy and compares files.
- Stores and replaces the Restic password through Windows Credential Manager. A new password replaces the old one only if it opens the existing repository.
- Shows snapshot scope without exposing free-form tags, paths, or other private metadata.

## Known limitations

- Snapshots stay on the current computer. Remote backup is deferred and does not protect against disk loss.
- In this release, a Calibre-plus-Kindle snapshot does not yet include the app's SQLite state.
- Physical Kindle transfer and full KOReader-to-Hardcover reading sync still need end-to-end validation.
- Proposed KOReader–Calibre metadata changes require review before they are applied.
- Hardcover journal entries and ratings remain manual actions.

## Windows package files

- `KOReaderEcosystem-Setup.exe` — Windows x64 installer.
- `KOReaderEcosystem-Windows-x64.zip` — portable Windows x64 package.
- `SHA256SUMS.txt` — SHA-256 hashes for both packages.

The installer is not digitally signed. Publish a release only after CI, packaging, hash validation, and executable review succeed.
