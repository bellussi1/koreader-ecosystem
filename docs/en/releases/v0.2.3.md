# KOReader Ecosystem v0.2.3

[English](v0.2.3.md) | [Português (Brasil)](../../releases/v0.2.3.md)

This release preparation was superseded by v0.2.4 after CI failures on the v0.2.3 tag. The existing tag was not reused; the changes were included in the next release.

## New features

- Restic snapshots include allowlisted local app state with Calibre and, when selected, the Kindle.
- The KOReader–Calibre SQLite database is copied with SQLite's Online Backup API and checked before entering the snapshot.
- Configuration without credentials and sanitized operation history are included; tokens, the Restic password, staging, temporary cache, and plugin rollback copies are excluded.
- New snapshots receive the `application-state-v1` tag; the UI distinguishes older snapshots that do not include app state.
- Restore verification also compares the app-state manifest. Restore creates a new folder and does not automatically reimport files into the active Windows profile.
- A local snapshot passed Restic checks and temporary restore verification.

## Limitations

- Backups remain on the same disk as their sources; remote copy is deferred.
- The app does not yet reimport recovered state into the active Windows profile.
- Physical MTP transfer and KOReader-to-Hardcover reading sync still require end-to-end validation.

## Windows files

- `KOReaderEcosystem-Setup.exe` — Windows x64 installer.
- `KOReaderEcosystem-Windows-x64.zip` — portable Windows x64 package.
- `SHA256SUMS.txt` — SHA-256 hashes for both distribution files.
