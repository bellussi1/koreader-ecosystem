# KOReader Ecosystem v0.2.0

[English](v0.2.0.md) | [Português (Brasil)](../../releases/v0.2.0.md)

Windows x64 release.

## New features

- Full Calibre library in cover cards with search, sorting, and bibliographic details.
- Hardcover shelves for **Quero ler** (Want to Read), **Lendo** (Currently Reading), and **Lidos** (Read), with a digital/eBook filter and a most recently updated reading card.
- Add a book through the native file picker, review duplicates, and explicitly attach a format or create a separate record.
- Edit metadata through `calibredb` with Calibre closed, a prior Restic snapshot, and reread verification.
- Manually send a format to Kindle over WPD/MTP without a drive letter or overwriting existing files; the app attempts SHA-256 verification.
- Explicit handling for filename collisions, backup failures, uncertain results, and hash mismatches.

## Before daily use

- Configure and validate your own Hardcover API key locally. Never include keys in chats, issues, or logs.
- Complete a real Kindle transfer and open the file in KOReader.
- Confirm a Wi-Fi reading sync and check progress on Hardcover.
- The Electron editor does not yet change covers or custom Calibre fields.
- Remote backup is deferred; local snapshots remain on the same disk as their sources.

The installer is not digitally signed. See the [v0.1.2 notes](v0.1.2.md) for the previous release.
