# KOReader Ecosystem v0.2.9

[English](v0.2.9.md) | [Português (Brasil)](../../releases/v0.2.9.md)

## What's new

- Adds English and Brazilian Portuguese interface languages with a selector in **Settings → Language**. On first launch, the app follows the Windows language.
- Localizes the library, Hardcover shelves, KOReader sync, reading history, backup, restore, and common error messages.
- Adds English README screenshots with fictional demo books and covers for international contributors.
- Fixes a local-service status label that remained in Portuguese in the English interface.

## Compatibility and limitations

- The selected language is stored in this app's local preferences.
- This release does not change data formats or remote synchronization behavior.
- USB/MTP transfer and the real KOReader–Hardcover reading cycle still need validation on the physical device.
- The installer is not digitally signed.

## Windows files

- `KOReaderEcosystem-Setup.exe` — Windows x64 installer.
- `KOReaderEcosystem-Windows-x64.zip` — portable Windows x64 package.
- `SHA256SUMS.txt` — SHA-256 hashes for both files.
